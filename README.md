# Desenvolvimento Web

Repositório destinado ao armazenamento de exercícios, atividades e projetos desenvolvidos durante meus estudos de **Desenvolvimento Web**.

## Conteúdos

Neste repositório serão adicionados exercícios relacionados a:

- HTML
- CSS
- JavaScript
- PHP
- Outras tecnologias e linguagens que forem estudadas ao longo da disciplina

## Organização

Os exercícios estão organizados em pastas individuais:

    desenvolvimento-web/
    └── exercicios/
        ├── exercicio-01/
        ├── exercicio-02/
        ├── exercicio-03/
        └── ...

Cada exercício pode conter seus próprios arquivos, como:

- `index.html`
- `style.css`
- `script.js`
- `README.md`

O arquivo `README.md` de cada exercício contém uma breve explicação sobre a atividade e os conceitos praticados.

## Objetivo

Organizar e acompanhar minha evolução nos estudos de **Desenvolvimento Web**, mantendo um histórico das atividades realizadas ao longo da formação em **Análise e Desenvolvimento de Sistemas**.
